# Avisos de terceiros

## TensorFlow EfficientDet-Lite0

O Eyes Project usa como baseline um modelo EfficientDet-Lite0 publicado pelo
TensorFlow e pré-treinado no COCO 2017.

- Modelo: `efficientdet-lite0-coco2017-int8`
- Publisher: TensorFlow
- Licença informada no model card: Apache License 2.0
- Model card: <https://www.kaggle.com/models/tensorflow/efficientdet/tfLite/lite0-detection-default>
- Texto da licença: <https://www.apache.org/licenses/LICENSE-2.0>

O artefato não é redistribuído neste repositório. Qualquer aplicação que o
incorpore deve preservar a atribuição e fornecer o texto da licença aplicável.
